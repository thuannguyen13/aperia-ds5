## Publishing Code Connect

Run this from `aperia-ds5` to push all mappings to Figma Dev Mode:

```bash
npm run cc:publish
```

Individual publish (e.g. icons only):

```bash
npx figma connect publish -f components/ui/icon/icons.figma.tsx --skip-validation
```

## Changelog

### 2026-05-08
- Added Code Connect mapping for **Input** (`input.figma.ts`)
  - `Variant` (Default/Password/File) → `type` prop (omitted for Default, `"password"` or `"file"` otherwise)
  - `State` (Disabled) → `disabled`; (Invalid) → `aria-invalid`; Focus/Filled are visual-only with no code equivalent
- Added Code Connect mappings for **InputGroup** (`input-group-addon-inline.figma.ts`, `input-group-addon-block.figma.ts`)
  - Addon Inline: `Variant` drives addon content — Text variant uses `<InputGroupText>`, Button/Spinner resolved via `executeTemplate()`
  - Addon Block: `Align` (Start/End) → `align="block-start|block-end"`; addon slots controlled by four BOOLEAN props; nested Addon Inline instances resolved via `findConnectedInstances`

### 2026-05-07 (update 2)
- Added Storybook stories for **Tabs** (Default, Line, Vertical, WithIcons, Disabled)
- Added Code Connect mappings for **Tabs**, **TabsTrigger**
  - `Variant` (Default/Line) drives `TabsList variant` prop
  - `Orientation` (Default/Vertical) drives `Tabs orientation` prop
  - `Items` SLOT renders trigger children inside `TabsList`
  - `TabsTrigger` uses `State=Disabled` → `disabled` prop; Badge/Active/Variant omitted (no code equivalent)
  - Icon resolved dynamically via `findInstance('IconPlaceholder')` → `executeTemplate()`

### 2026-05-07 (update)
- Added Code Connect mappings for **Avatar**, **AvatarBadge**, **AvatarGroup**
  - `Type` (Image/Fallback/Icon) drives rendered children
  - `Size` xl/xs remapped to lg/sm (code only exposes sm/default/lg)
  - `Show Badge` gates `<AvatarBadge />` as a nested connected instance
  - `AvatarGroup` uses SLOT `Items` for child avatars

### 2026-05-07
- Added Code Connect mapping for **Alert** (`Alert.figma.ts`)
- Added Storybook stories for all 15 components
- Upgraded Storybook to v10.3.6
- Removed Style Dictionary — tokens now hand-authored in `styles/base.css`
- Aligned `base.css` to official shadcn zinc Tailwind v4 defaults
