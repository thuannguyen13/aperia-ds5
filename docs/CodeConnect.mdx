## Publishing Code Connect

Each Figma component maps to one template, `<kebab-name>.figma.ts`, beside its code component in `components/ui/<name>/`. Run these from `aperia-ds5`:

```bash
npm run cc:publish -- --dry-run   # list what would publish, upload nothing
npm run cc:publish                # publish all component templates to Figma Dev Mode
npm run publish:icons             # publish the icon templates
```
