# Build your own data table

Use `DataTable` first. Build your own only when a screen needs one of these:

- A different layout: no Columns menu, no pagination, or the table inside a card.
- Actions on the selected rows, such as export or bulk edit.
- State the app owns: server-side paging, sorting or filtering, or selection that other parts of the page read.

`DataTable` is made from the same parts listed below, so a table you build looks the same as the ready one. Every part
of a data table is a part of a list: the toolbar is `ListToolbar`, and the count and pages are `ListPager`.

## Put the parts together

`useDataTable` holds the search, the filters, the sort, column visibility, the selection and the page. Pass the table it
returns to the parts and leave out any part you do not need.

```tsx
import { Button } from "aperia-ds5"
import {
  DataTableContent,
  DataTablePagination,
  DataTableToolbar,
  useDataTable,
} from "aperia-ds5/data-table"

const NOUN = ["merchant", "merchants"] as const

export function MerchantTable() {
  const table = useDataTable({ columns, data: merchants })
  const selected = table.getFilteredSelectedRowModel().rows

  return (
    <div className="w-full">
      <DataTableToolbar
        table={table}
        search={{ placeholder: "Search merchants" }}
        filters={{ fields: filterFields }}
        sort={[{ value: "volume", label: "Volume", starts: "desc" }]}
        noun={NOUN}
        actions={
          <Button variant="outline" disabled={!selected.length} onClick={() => exportRows(selected)}>
            Export {selected.length || ""}
          </Button>
        }
      />
      <DataTableContent table={table} />
      <DataTablePagination table={table} noun={NOUN} />
    </div>
  )
}
```

`columns` is the same array you would pass to `DataTable`. Each filter field's `id` and each sort option's `value` is a
column's id. Headings are plain text, such as `header: "Merchant"`: the list sorts from Sort, not from its headings.

## Own the state

When the server does the paging, sorting or filtering, call TanStack's `useTable` with `dataTableFeatures` and hold the
state yourself. The parts accept that table too. `DataTableToolbar` writes the search to `globalFilter` (or to the
column named by `search.column`), each column's filters to `columnFilters` as `{ type, rules }` (`FilterRule`, the
same model `filterRows` reads), and Sort to `sorting`. Send those to the server.

```tsx
import { dataTableFeatures, useTable, DataTableContent, DataTablePagination } from "aperia-ds5/data-table"

const [pagination, setPagination] = React.useState({ pageIndex: 0, pageSize: 25 })
const { rows, pageCount } = useMerchants(pagination) // your API call

const table = useTable({
  features: dataTableFeatures,
  data: rows,
  columns,
  manualPagination: true,
  pageCount,
  state: { pagination },
  onPaginationChange: setPagination,
})

<DataTableContent table={table} />
<DataTablePagination table={table} noun={NOUN} />
```

A table on `useTable` that filters its own rows passes `defaultColumn: dataTableDefaultColumn<Merchant>()`, so the
toolbar's filters apply. The [TanStack Table docs](https://tanstack.com/table/latest) cover the other options:
`manualSorting`, `manualFiltering`, controlled `rowSelection`.

## Parts

| Part | What it renders |
|---|---|
| `DataTable` | The ready table: the toolbar, the table, and the count and pages |
| `useDataTable` | No UI. Returns a table with search, filter, sort, visibility, selection and paging state |
| `DataTableToolbar` | The list's toolbar (`ListToolbar`): search, filters, the Columns menu in its slot, Sort, and `actions` |
| `DataTableContent` | The table: the heading row, the rows, and No Results with Clear Filters when nothing matches |
| `DataTableViewOptions` | The Columns menu that shows and hides columns; `DataTableToolbar` puts it in its slot |
| `DataTablePagination` | The count and the pages (`ListPager`) |
| `dataTableFeatures` | The TanStack feature set the parts expect, for `useTable` |
| `dataTableDefaultColumn` | The column filter the toolbar's filters need, for `useTable` |
| `DataTableFilter` | Deprecated. Use `DataTableToolbar`'s `search` |
| `DataTableColumnHeader` | Deprecated. Headings do not sort; write `header: "Merchant"` |

Everything else from `@tanstack/react-table` is re-exported from `aperia-ds5/data-table`, so one import line covers a
table.
