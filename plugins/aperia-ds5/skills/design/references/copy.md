# Copy

Clear, direct, professional, human. Confident without trying to impress.

## Principles

- **Concrete over clever.** Name the object and the action: Add Contact, Delete Note, Change to Demo. Never Manage,
  Continue, Get Started or Take Action when a specific verb exists.
- **No narrative.** Say only what the user needs to act. Never explain where data is saved, what it counts toward, what
  the system does next or why a rule exists.
- **One word per concept.** Use the app's established terms (its glossary). Don't introduce synonyms. A new term goes in
  the glossary with the change.
- **No SaaS or AI voice.** Not "Let's get started", "Seamlessly", "Unlock", "You're all set!" or "Great!".

## By element

| Element | Write | Not |
|---|---|---|
| Page title | What the page holds: "Prospects" | "Your Prospect Workspace" |
| Section heading | What the section holds: "Recent Activity" | "Stay on Top of Things" |
| Button | Verb plus object: "Add Member" | "Submit", "Continue" |
| Link | Destination: "View All" | "Click Here" |
| Label | The field's name: "Start Date" | "Please enter the start date" |
| Placeholder | An example or format: "name@example.com" | "Enter your email here" |
| Empty state | "No Tasks", plus a line only when it adds whose, which or what to do | "No tasks yet." under "No Tasks" |
| Error | The cause and the fix: "File must be smaller than 10 MB." | "Something went wrong." |
| Validation | Beside the field, what must change: "Enter a valid email address." | "Invalid input." |
| Toast | The result: "Changes saved." | "Great! Your changes have been saved!" |
| Confirmation | "Delete Project?" / "This permanently deletes the project and its files." / **Delete Project** · Cancel | "Are you sure?" / OK |
| Tooltip | Only when the UI needs it, saying the action or why it's disabled | "Click here to edit" |

## Fixed phrases

- A locked or undeletable item: **"This item is in use and can't be [deleted/changed/removed]."**, word for word. No
  "so" clause, and don't name what uses it. On a disabled Delete it's the button's tooltip.
- A hidden amount: **$XX,XXX**.
- An optional field's label ends with **"(Optional)"**.
- A missing value: **—**, an em dash with no spaces around it, in muted text. Not `-`, N/A or 0.
- An empty optional value: **"No [field]"** (No priority, No assignee).
- A change of state says **Change** (Change to Demo, Reason for Change). **Move** is for physically moving rows or cards.
- A status says the state (Draft, Active, Completed), not "Successfully Completed".

## Case

Title Case for titles, headings, tabs, table headers, labels and buttons. Sentence case for sentences, descriptions,
values, toasts and tooltips.
